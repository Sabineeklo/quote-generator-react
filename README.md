# Quote Generator – React

Application front-end développée en React permettant de générer des citations aléatoires à partir d’une API externe.

## 🎯 Objectif
L’objectif de ce projet est de mettre en pratique les bases et bonnes pratiques du développement front-end avec React, en mettant l’accent sur la gestion d’état, la structuration des composants et l’expérience utilisateur.

---

## ✨ Fonctionnalités
- Génération de citations aléatoires via une API externe
- Ajout et suppression de citations en favoris
- Page dédiée pour consulter les favoris
- Partage d’une citation
- Persistance des favoris via le localStorage
- Gestion des états (loading, error)
- Interface responsive

---

## 🛠️ Stack technique
- React
- TypeScript
- Tailwind CSS
- React Router
---

## 📂 Architecture
Le projet est structuré autour de composants réutilisables, de pages dédiées et de services pour la gestion des appels API et du stockage local.

---

## 🚀 Lancer le projet en local
```bash
npm install
npm run dev
```
